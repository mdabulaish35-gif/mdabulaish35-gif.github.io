A modern, responsive personal portfolio website built to showcase my skills, projects, services, education, and professional profile as a BCA student and aspiring software developer.

**[Visit My Portfolio](https://mdabulaish35-gif.github.io/)**

## 📌 About The Project

This is my personal portfolio website, designed to create a professional online presence and showcase my journey in software development.

The website provides information about me, my technical skills, projects, services, and ways to get in touch with me.

It is designed with a clean and modern user interface and is responsive across desktop, tablet, and mobile devices.

---

## ✨ Features

- 🏠 Modern Home/Hero section
- 👨‍💻 About Me section
- 💼 Projects showcase
- 🛠️ Skills section
- 🚀 Services section
- 📩 Contact page
- 📧 Functional contact form using Formspree

- 🌙 Dark/Light mode
